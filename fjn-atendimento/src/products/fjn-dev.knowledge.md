# Dossiê — FJN Desenvolvimento

## O que é

A **FJN Tecnologia** oferece serviços de desenvolvimento de software sob demanda para empresas que precisam de soluções customizadas.

## Tipos de projeto que a FJN faz

- **Sites institucionais e landing pages** (Next.js, WordPress)
- **Sistemas web personalizados** (SaaS, ERPs internos, dashboards)
- **Aplicativos** (web app, PWA, mobile híbrido)
- **Automações e integrações** (n8n, Zapier, APIs)
- **Bots de atendimento** (WhatsApp, Instagram)
- **Consultoria técnica** e arquitetura de sistemas

## Stack principal

- **Frontend:** React, Next.js, TypeScript
- **Backend:** Node.js, NestJS, PostgreSQL
- **Mobile:** React Native, PWA
- **Infra:** VPS, Vercel, AWS, Cloudflare
- **IA:** Integrações com Claude, OpenAI

## Como qualificar um pedido de desenvolvimento

Antes de passar para humano, capture sempre:

1. **Tipo de projeto** — site? sistema? automação? app?
2. **Objetivo** — o que precisa resolver?
3. **Tem briefing/documentação?** ou começa do zero?
4. **Prazo desejado**
5. **Orçamento aproximado** (faixa)
6. **Nome da empresa / cliente**
7. **Site/Instagram atual** (se tiver)
